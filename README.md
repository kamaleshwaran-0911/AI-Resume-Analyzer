# AI-Resume-Analyzer

An AI-powered web application that analyzes resumes, evaluates candidate profiles, and generates downloadable PDF reports with actionable insights.

🚀 Live Demo

Live Application: https://ai-resume-analyzer-iy8r.onrender.com

GitHub Repository: https://github.com/kamaleshwaran-0911/AI-Resume-Analyzer

---

📌 Project Overview

AI Resume Analyzer is a Flask-based web application designed to help job seekers evaluate and improve their resumes. The system extracts information from uploaded PDF resumes, analyzes relevant skills, calculates a resume score, and generates a professional PDF report containing personalized feedback.

---

✨ Features

- 📄 Upload and analyze PDF resumes
- 🔍 Extract resume content automatically
- 📊 Resume scoring and evaluation
- 💡 Skill-based recommendations
- 📑 Downloadable PDF analysis report
- 🌐 Web-based user interface
- ☁️ Deployed on Render
